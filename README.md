# Smart Calculator

## About the Project
Smart Calculator is a web-based calculator application developed using Python and Flask. It provides a simple and user-friendly interface to perform basic mathematical calculations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User-friendly web interface
- Fast calculation results

## Technologies Used
- Python
- Flask
- HTML5
- CSS3

## Project Structure
```text
Smart-Calculator/
│
├── app.py
├── templates/
│   └── index.html
├── static/
│   └── style.css
└── README.md
```

## Installation and Setup

1. Clone the repository:
```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:
```bash
cd Smart-Calculator
```

3. Install Flask:
```bash
pip install flask
```

4. Run the application:
```bash
python app.py
```

5. Open your browser and visit:
```text
http://127.0.0.1:5000/
```
